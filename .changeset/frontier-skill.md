Add `/frontier`: work out what to do next across an issue tracker. It derives each issue's touch set as an `area:*` label, wires the blocking edges the tracker is missing, groups the issues that should land as a single pull request into batches with a gate command each, and serves a live read-only board on localhost. Adds **Batch**, **Touch set** and **Gate** to `CONTEXT.md`, and a "Frontier operations" section to the GitHub, GitLab and local tracker seeds.
